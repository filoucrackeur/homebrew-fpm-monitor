# Homebrew tap: filoucrackeur/fpm-monitor

Homebrew tap for [php-fpm-monitor](https://github.com/filoucrackeur/php-fpm-monitor),
a PHP-FPM pools monitor written in Rust.

## Install

```sh
brew tap filoucrackeur/fpm-monitor
brew install fpm-monitor
```

The formula is regenerated on every release and points to the binaries
attached to the matching GitHub release (see the `Formula/` directory).
